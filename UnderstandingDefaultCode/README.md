# Understanding the Default Code

## Problem

Write the complete Java program discussed in the lesson to print the sum of `12` and `7`.

The program should output:

```text
19
```

## Approach

A basic Java program contains a class and a `main()` method.

The class is declared using:

```java
class Codechef
```

The `main()` method is:

```java
public static void main (String[] args)
```

Inside the `main()` method, we use `System.out.println()` to calculate and print the sum:

```java
System.out.println(12 + 7);
```

The addition is performed first, and the result `19` is printed.

## Solution

```java
class Codechef
{
    public static void main (String[] args)
    {
        System.out.println(12 + 7);
    }
}
```

## Output

```text
19
```

## Concepts Used

- Java class declaration
- `main()` method
- `public`, `static`, and `void`
- `String[] args`
- Curly braces `{ }`
- `System.out.println()`
- Addition operator `+`
