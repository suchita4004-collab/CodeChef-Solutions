# Subtraction and Division

## Problem

Write a Java program that performs the following operations:

1. Print the result of subtracting `2` from `9`.
2. Print the result of dividing `30` by `5`.

## Approach

Java provides different arithmetic operators for performing mathematical operations.

| Operator | Operation | Example |
|---|---|---|
| `+` | Addition | `a + b` |
| `-` | Subtraction | `a - b` |
| `*` | Multiplication | `a * b` |
| `/` | Division | `a / b` |

For subtraction, we use:

```java
System.out.println(9 - 2);
```

For division, we use:

```java
System.out.println(30 / 5);
```

## Solution

```java
class CodeChef {
    public static void main(String[] args) {
        System.out.println(9 - 2);
        System.out.println(30 / 5);
    }
}
```

## Output

```text
7
6
```

## Concepts Used

- Java arithmetic operators
- Subtraction operator `-`
- Division operator `/`
- `System.out.println()`
- Basic mathematical operations
