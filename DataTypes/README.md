# Data Types in Java

## Problem

Write a Java program that:

1. Creates an integer variable named `number`.
2. Assigns the value `19` to `number`.
3. Prints the value of `number`.

## Approach

In Java, every variable has a **data type** that tells Java what kind of data the variable will store.

For integers, we use the `int` data type.

We create the required variable using:

```java
int number = 19;
```

Then we print the value using:

```java
System.out.println(number);
```

Since `number` is a variable, we don't use double quotes around it.

## Solution

```java
class CodeChef {
    public static void main(String[] args) {
        int number = 19;
        System.out.println(number);
    }
}
```

## Output

```text
19
```
