# Print a Number

## Problem

Write a Java program to output the number **12**.

## Approach

In Java, we use `System.out.println()` to print something on the screen.

Here, we use:

```java
System.out.println(12);
```

This prints `12` as the output.

## Solution

```java
class CodeChef {
    public static void main(String[] args) {
        System.out.println(12);
    }
}
```

## Output

```text
12
```

## Concepts Used

- Java class
- `main()` method
- `System.out.println()`
- Basic Java program structure

**Java**
