# Variables in Java

## Problem

Create a variable named `age` and assign the value `25` to it.

Then print the value of the `age` variable.

## Approach

A variable is used to store data in a program.

In Java, we can create an integer variable using the `int` data type:

```java
int age = 25;
```

Here:

- `int` is the data type for integers.
- `age` is the variable name.
- `25` is the value stored in the variable.

We can print the value of the variable using:

```java
System.out.println(age);
```

We don't use double quotes when printing a variable because we want Java to print the value stored in the variable.

## Solution

```java
class CodeChef {
    public static void main(String[] args) {
        int age = 25;
        System.out.println(age);
    }
}
```

## Output

```text
25
```
