# Addition of Variables

## Problem

Write a Java program that:

1. Declares two integer variables `a` and `b`.
2. Assigns `23` to `a` and `20` to `b`.
3. Prints the sum of `a` and `b`.

## Approach

First, we declare two integer variables and assign values to them:

```java
int a = 23;
int b = 20;
```

Then, we add the two variables using the `+` operator:

```java
System.out.println(a + b);
```

The sum is:

```text
23 + 20 = 43
```

## Solution

```java
class CodeChef {
    public static void main(String[] args) {
        int a = 23;
        int b = 20;

        System.out.println(a + b);
    }
}
```

## Output

```text
43
```
